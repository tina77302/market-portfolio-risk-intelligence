# Stress 검증: 상황별 오차 분석

**기존 첫 수정 모델을 재학습하지 않고 상황별 실패 양상을 진단했습니다.**
대상은 2021-01-05~2026-10-14의 비중첩 10거래일 구간 145개, 28개 자산과 변경 전·후 예시 포트폴리오입니다.
이번 결과는 사후 진단이며, 해당 상황을 미리 식별하는 성능이나 새로운 홀드아웃의 정확도가 아닙니다.
기존의 별도 고정 위기 사례는 이 145개 구간에 추가 합산하지 않았습니다. 따라서 2020년 코로나 사례는 이 기간 분류의 표본 수에 포함되지 않습니다.

## 주요 관측

- 주식 급락 표본은 동반 충격 2개, 금리 급등 기준 미충족 3개 구간입니다. 극단 충격에서 일정한 보정 방향을 추정하기에는 부족합니다.
- before: 두 기준 모두 미충족인 117개 구간은 전체 관측의 80.7%, 전체 절대오차의 80.2%입니다. 오차의 대부분이지만 표본 자체도 대부분이므로 이 상황만의 특수한 실패라고 단정하지 않습니다.
- before: 세부 15개 셀 중 n≥5인 곳에서 MAE가 가장 큰 상황은 **SPY (−5%,−2%] / 금리 ≥+20bp**이며 2.91%p, n=7입니다. 표본 안에서 사후 선택한 관측이며 새 경보·모델 선택 규칙이 아닙니다.
- after: 두 기준 모두 미충족인 117개 구간은 전체 관측의 80.7%, 전체 절대오차의 79.4%입니다. 오차의 대부분이지만 표본 자체도 대부분이므로 이 상황만의 특수한 실패라고 단정하지 않습니다.
- after: 세부 15개 셀 중 n≥5인 곳에서 MAE가 가장 큰 상황은 **SPY (−5%,−2%] / 금리 ≥+20bp**이며 2.00%p, n=7입니다. 표본 안에서 사후 선택한 관측이며 새 경보·모델 선택 규칙이 아닙니다.

표본이 작은 동반 충격이나 기준에 민감한 구간의 평균만으로 새 모델·보정 계수를 채택하지 않습니다.
아래의 방향·전후반·기준 민감도를 함께 보고 반복되는 관측과 가설을 구분해야 합니다.

## 다음 수정에 대한 판단

- before: 두 기준 모두 미충족 상황의 평균 실제−추정은 전반 -0.88%p / 후반 +0.13%p입니다. 금리 급등 기준만 충족 상황은 전반 -0.47%p / 후반 -0.67%p이며, 9개 정의의 전체 기간 편향 범위는 -1.02~+0.29%p입니다.
- before: 기본 금리 급등 상황의 전체 평균 실제−추정은 -0.53%p지만, 실제 손실 16개 구간에서는 +0.36%p, 실제 이익 7개 구간에서는 -2.58%p입니다. 전체 평균이 추정을 보수적으로 보이게 하더라도 실제 손실 구간까지 보수적이라고 볼 수 없습니다.
- after: 두 기준 모두 미충족 상황의 평균 실제−추정은 전반 -0.66%p / 후반 +0.06%p입니다. 금리 급등 기준만 충족 상황은 전반 -0.53%p / 후반 -0.69%p이며, 9개 정의의 전체 기간 편향 범위는 -1.05~+0.09%p입니다.
- after: 기본 금리 급등 상황의 전체 평균 실제−추정은 -0.58%p지만, 실제 손실 17개 구간에서는 +0.06%p, 실제 이익 6개 구간에서는 -2.39%p입니다. 전체 평균이 추정을 보수적으로 보이게 하더라도 실제 손실 구간까지 보수적이라고 볼 수 없습니다.

기본 분류에서 반복된 방향이 있더라도 임계값 변경·기간 분할에서 방향이 달라지면 전체에 같은 보정값을 더하거나 빼는 방식의 근거로 사용하기 어렵습니다.
따라서 이번 진단만으로 상황별 모델 전환이나 고정 편향 보정을 추가하지 않습니다. 우선 첫 수정 모델을 고정하고 새 기간의 상황별 오차를 누적하며, 과거 자료만으로 산출한 오차 범위의 실제 포함률을 별도 검증하는 것이 다음 후보입니다. 오차 범위나 포함률 자체를 이번 작업에서 계산한 것은 아닙니다.

## 상황 정의와 전체 오차 분해

- 주식 급락: 관측된 10일 SPY 수익률 ≤ −5%.
- 금리 급등: 같은 10일 DGS10 변화 ≥ +20bp.
- 동반 충격 / 주식 급락 기준만 충족 / 금리 급등 기준만 충족 / 두 기준 모두 미충족의 네 가지로 서로 겹치지 않게 분류합니다.
- ‘기준만 충족’은 다른 시장 변화가 없었다는 뜻이 아닙니다. ‘두 기준 모두 미충족’도 정상·안전 판정이 아닙니다.
- 이 임계값은 이번 진단용 고정 규칙이며 업계 표준·보정된 경보 기준이 아닙니다. 결과에 맞춰 선택하지 않았고 아래의 고정 3×3 민감도 비교도 모두 공개합니다.

양수 손실, 음수 이익입니다. `실제−추정`이 양수이면 실제 결과가 더 손실 쪽에 있음을 뜻하며, 실제가 이익인 구간에서는 이익을 과대 추정한 경우도 포함합니다.
실제 손실 구간만의 과소추정은 별도 열로 제시합니다. n=0은 N/A, n<5는 작은 표본으로 표시합니다. n≥5도 통계적 신뢰성이 확보됐다는 뜻은 아닙니다.

MAE가 큰 상황과 전체 오차를 많이 차지하는 상황은 표본 비중 때문에 다를 수 있습니다.
