# 포트폴리오 시연 실행 가이드

포트폴리오 API와 대시보드를 띄우고, 발표 시연을 STEP 1~6 순서로 진행하는 방법입니다. 데이터는 리포에 고정된 스냅샷(2026-10-23 기준)을 쓰므로 따로 내려받을 필요가 없습니다.

## 준비물

| 항목 | 버전 | 확인 명령 |
| --- | --- | --- |
| Python | 3.12 이상 | `python --version` |
| Node.js | 20.9 이상 (Next.js 16 요구) | `node --version` |

## 1. 설치 (처음 한 번)

```bash
pip install -r requirements.txt
cd frontend && npm ci && cd ..
```

## 2. 실행 (터미널 2개)

**터미널 1 — 포트폴리오 API** (저장소 루트에서)

```bash
uvicorn src.portfolio.server:app --port 8000
```

`http://localhost:8000/health`가 `{"status":"ok","as_of":"2026-10-23"}`를 돌려주면 정상입니다.

**터미널 2 — 대시보드**

```bash
cd frontend
npm run dev
```

`http://localhost:3000/portfolio`를 엽니다. 사이드바의 "포트폴리오 분석" 메뉴로도 들어갈 수 있습니다.

주소나 포트를 바꿀 때는 두 가지를 함께 맞춥니다.

- 대시보드가 부를 API 주소: `NEXT_PUBLIC_PORTFOLIO_API_URL=http://<host>:<port> npm run dev`. 빌드할 때 값이 고정되므로 `npm run build` 전에 설정합니다.
- API가 허용할 대시보드 주소: `PORTFOLIO_API_CORS_ORIGINS=http://<대시보드 주소>`. 여러 개는 쉼표로 구분합니다. 기본값은 `http://localhost:3000`입니다.

## 3. 발표 전 점검 (2분)

```bash
python -m src.portfolio.demo --check            # 시연 수치가 기록(examples/portfolio/expected.json)과 같은지
python -m pytest -q tests/test_portfolio_*.py   # 포트폴리오 테스트
cd frontend && npm run build                    # 대시보드 빌드
```

`demo --check`가 실패하면 데이터나 계산이 바뀐 것입니다. 아래 표의 수치를 다시 확인한 뒤 발표합니다.

## 4. 시연 순서와 기준 수치

평가금액은 USD 100,000이고, 모든 수치는 2026-10-23 스냅샷, 756거래일(2023-10-19 ~ 2026-10-23) 기준입니다.

| STEP | 화면 | 할 일 | 보여줄 내용 |
| --- | --- | --- | --- |
| 1 | 시장 위험 | 미국 시장 카드 확인 | Risk Score는 시장 수준 신호이지 이 포트폴리오의 손실확률이 아닙니다. 확정 관측값이 없는 날은 점수를 만들거나 이월하지 않으므로 N/A가 나올 수 있습니다. |
| 2 | 포트폴리오 입력 | 기본 예시(빅테크 집중형)로 "분석" | AAPL·MSFT 30%, NVDA·AMZN 20% |
| 3 | Hidden Risk Map | 비중 vs 위험 기여도, 섹터, 상관 | 4종목이지만 IT 80%. NVDA는 비중 20%인데 위험 기여도 30.4%. 종목 간 상관 0.30~0.53, 연율 변동성 23.38% |
| 4 | Stress Test | 시나리오 카드 3개 | 주식 급락 손실 30.2%($30,163), 변동성 충격 26.8%($26,757). 금리 충격은 회색이며 0과 구분되지 않습니다(t 1.21). |
| 5 | What-if | "예시: 30%를 장기국채(TLT)로" 후 "비교" | 기존 종목을 70%씩 남기고 30%를 TLT로 옮깁니다. |
| 6 | Before / After | 비교표 | 아래 표 |

| 지표 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 연율 변동성 | 23.38% | 16.94% |
| 최대 섹터 비중 (IT) | 80% | 56% |
| 최대 자산 비중 | 30% (AAPL) | 30% (TLT) |
| Market 베타 | 1.30 | 0.94 |
| 주식 급락 손실 | 30.16% ($30,163) | 21.95% ($21,953) |
| 변동성 충격 손실 | 26.76% ($26,757) | 19.08% ($19,083) |
| 금리 충격 손실 | −0.84%, 0과 구분 안 됨 (t 1.21) | **2.33% ($2,331), 유의 (t −4.66)** |

핵심 메시지: 빅테크 비중을 장기국채로 옮기면 주식·변동성 충격 손실은 줄지만, 이전에는 없던 금리 위험이 새로 생깁니다. 최대 자산 비중은 30% 그대로이고, 가장 큰 자산이 AAPL에서 TLT로 바뀝니다.

해석할 때 주의할 점:

- 흐린 값은 |t| < 2로 0과 구분되지 않는 값입니다.
- 시나리오별 손실은 합산하지 않습니다.
- 모든 손익은 일간 베타에 과거 10거래일 충격을 곱한 선형 추정이며, 미래 손실 예측이 아닙니다.

## 5. 문제 해결

| 증상 | 원인과 해결 |
| --- | --- |
| "포트폴리오 API 서버에 연결할 수 없습니다" | 터미널 1의 API가 꺼져 있습니다. API를 먼저 실행합니다. |
| 브라우저 콘솔에 CORS 오류 | 대시보드 주소가 API 허용 목록에 없습니다. `PORTFOLIO_API_CORS_ORIGINS`를 맞춥니다. |
| 시장 카드에 N/A | 정상입니다. 해당 날짜에 확정 관측값이 없으면 점수를 만들거나 이월하지 않습니다. |
| 8000번 포트 사용 중 | `--port 8001`로 띄우고 `NEXT_PUBLIC_PORTFOLIO_API_URL`도 같은 포트로 바꿉니다. |
| 수치가 위 표와 다름 | `python -m src.portfolio.demo --check`로 확인합니다. 데이터를 새로 받으면(`python -m src.portfolio.data` 이후 snapshot, scenarios 재생성) 수치가 바뀝니다. |
